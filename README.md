# Painel Comercial CGLUB

Painel interno da CGLUB (distribuidora Lubrax BA/SE). Reúne:

- desempenho da equipe em relação às metas;
- **Central do Gestor**;
- roteiro de visita **5Q3A**;
- cadastro de clientes;
- carteira de produtos Lubrax.

**Acesso restrito:** cada pessoa entra com o login criado pelo administrador e vê só o que as regras do perfil dela permitem. Este repositório contém apenas o código, sem nenhum dado de vendas. Os dados ficam num banco protegido.

## Para quem usa

1. Abra o endereço do painel e entre com seu login. No primeiro acesso, troque a senha temporária.
2. O **vendedor** vê a própria carteira e o ranking do canal (se liberado), faz o roteiro 5Q3A e registra visitas, inclusive sem internet.
3. O **gestor** vê a equipe dos canais dele, a Central do Gestor (quem precisa de ajuda, clientes parados, mix premium) e gera a pauta 1:1.
4. O **administrador** importa o SAP todo mês, edita metas e cadastros, cria usuários e define o que cada perfil vê.
